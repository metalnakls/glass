## Validation and blockers

- Main-window chrome: built and installed, native accessibility confirms no toolbar or traffic-light controls. Add Magnet retains Cancel/Add and shows free space. Existing 90 tests passed before the final guarded chrome layout update; final application build passed.
- Completion diagnosis: Wolf reported 0.9998 with 8,388,608 bytes remaining; Alaska 0.9998 / 8,388,608; Click 0.9997 / 2,097,152; Remember Me 0.9997 / 4,194,304; The Gift 0.9993 / 8,388,608. All had positive recorded completion dates. User explicitly chose historical completion over current missing bytes. No rounded-percentage threshold was introduced.
- Live completion verification after relaunch: all five are in Finished. Wolf currently also reports a storage error, so its question mark is retained. Preview eligibility is fixed; actual thumbnail recovery depends on reachable files and the Finder mapping.
- Inspector verified in the running app: compact hierarchical rows, no file previews/icons or Files heading, select-all checkbox, native mounted-share icon, and / Ultra label, and free-space value. Selection actions now occupy one inspector-bottom material bar across seasons; wanted edits remain staged until the server confirms them.
- List and grid use the same grouping, queue order, and sections. Cmd+1 selects grid, Cmd+2 list; Cmd-minus/plus choose compact/normal/large density. Native queue placement updates only moved torrents, including group members. API reference: [Transmission queue_position](https://github.com/transmission/transmission/blob/main/docs/rpc-spec.md#32-torrent-mutator-torrent_set).
- Swipe clipping was rebuilt around a full-width stationary action plane and a moving padded foreground, replacing native swipe clipping. Trackpad and synthetic wheel endings are handled. Physical swipe visibility, foreground/glow alignment, drag attraction, vertical highlight travel, folder fan transitions, and state-symbol animation still require visual testing. Synthetic swipe verification was interrupted because the app window became unavailable.
- Headers use native floating section rows and soft scroll-edge treatment. Verify push-out and selection/shadow ordering while a header is pinned. Dark appearance, grid arrangement, exact density, and modal Option behavior also need visual tuning.
- Post-add Smart Rename and file priority are wired to provider actions; file priority applies in batches. These write operations were not exercised against the user’s existing downloads during inspection.
- Automatic cache tests cover all recent servers despite the old disabled toggle/one-server limit and expiry beyond two calendar months. Successful deletion prunes the cache immediately; delayed cache saves take a fresh snapshot at execution.
- Multi-season modal polish: one search/select-all row spans all seasons, and the editable Large Title precedes the destination controls. Option bypass also removes the smart series-directory requirement.
- Final validation: 94 SwiftPM tests passed. The complete app built and installed through the canonical script; both built and installed signatures passed strict verification. Final gesture/table confirmation changes also passed all 94 tests and a fresh signed app build.
- Checkboxes above record implementation, not a claim that every animation or live server action has been visually verified. The follow-up inspector/empty-state design questions remain intentionally open.
