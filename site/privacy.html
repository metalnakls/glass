Glass privacy

Glass uses Sparkle to check for updates. Once per week, Sparkle sends the Glass version and macOS version with an update check. Glass uses aggregate counts of these checks to understand which versions are in use and support updates. This is a count of update-checking installations, not people or app launches.

Glass does not send a persistent device identifier. The metrics database stores only weekly counts grouped by Glass version and macOS version, without IP addresses or detailed hardware information. Cloudflare processes the network request to serve updates; its Worker invocation logs are disabled.
