Glass privacy

Glass reports its version, macOS version, Mac model identifier (such as Mac14,2), and a random installation ID on first launch and when these details change. Failed reports are retried on a later launch or activation. There is no daily heartbeat.

The installation ID is stored in local preferences; it is not a serial number or hardware identifier. The private metrics database keeps one current record per installation, including when it was first reported, when its current Glass version was first reported, and when details were last reported. These timestamps describe reports, not the exact installation time. Resetting preferences or copying them to another Mac can affect installation counts.

The collector does not store your Mac name, serial number, IP address, files, or torrent activity. Cloudflare processes network requests; Worker invocation logs are disabled. Older versions may send weekly aggregate Sparkle profiles.
