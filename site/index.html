Glass

A quiet torrent client for macOS.

Download the latest release

Install

Glass requires macOS 27 or later.

Releases are not signed with a Developer ID certificate, so macOS quarantines the download the first time. To open it:

  • Drag Glass.app into Applications, then right-click it and choose Open, or
  • Remove the quarantine flag from a terminal: 
    xattr -cr /Applications/Glass.app

After the first launch, Glass updates itself.

Updates

Updates arrive automatically through Sparkle. Check manually from the app menu with Check for Updates….
